## API 契约

```
GET    /api/projects                     → [{id, name, article_count}]
POST   /api/projects   {name}            → {id, name}
GET    /api/projects/{pid}/articles      → [{id, title, updated_at}]
POST   /api/projects/{pid}/articles {title} → {id, title}
GET    /api/articles/{aid}               → {id, title, blocks: [{id,type,text,attrs}]}
PUT    /api/articles/{aid} {title?, blocks} → {ok}
```

存储：`data/workbench.db`，两表 `projects(id INTEGER PK, name TEXT, created_at TEXT)`、`articles(id INTEGER PK, project_id INTEGER FK, title TEXT, blocks_json TEXT, created_at TEXT, updated_at TEXT)`。
