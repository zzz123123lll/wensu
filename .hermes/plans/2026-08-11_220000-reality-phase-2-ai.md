## 设置契约

```
GET  /api/settings → {configured: bool, base_url, model, has_key: bool}   # 不回传 key
PUT  /api/settings {base_url, model, api_key?}  → {ok}                    # api_key 缺省=保留原 key
POST /api/ai/ask      {prompt, context}   → {reply}
POST /api/ai/rewrite  {text}              → {candidates: [{label, text}]}
POST /api/ai/insight  {title, blocks}     → {insight: {...}, suggestions: [{icon,title,desc,action}]}
```

DPAPI：ctypes 调 CryptProtectData/CryptUnprotectData（stdlib 依赖，不引 pywin32），key 密文存 settings 表。

## 任务

### Task 1: settings 存储（TDD）
- `app/settings.py`：`get_settings(conn)` / `save_settings(conn, base_url, model, api_key=None)` / `has_key(conn)`；api_key 用 DPAPI 加密存 `settings(api_key_enc BLOB)`；其他明文列 base_url/model
- 测试：save/get 往返、key 加密后不等于明文、缺省保留

### Task 2: settings API（TDD）
- 路由 GET/PUT /api/settings；GET 永不返回 key
- 测试：PUT 后 GET configured=True；GET 响应无 api_key 字段

### Task 3: llm 客户端（TDD, MockTransport）
- `app/llm.py`：`LLMClient(base_url, api_key, model)`，`chat(messages, json_mode=False, timeout=60) -> str`；错误映射：401→"Key 无效"、超时→"请求超时"、空回复→"模型未返回内容"
- 测试：正常回复、json 模式、401 映射、空回复、超时

### Task 4: ai_service（TDD, mock llm）
- `ask(prompt, context)` → 组装消息 → reply
- `rewrite(text)` → 解析 2 候选（JSON 校验，失败降级拆行）
- `insight(title, blocks)` → 洞察 + 3 建议（JSON 校验，失败降级规则默认）
- 测试：prompt 含上下文、解析、降级路径

### Task 5: AI API 路由（TDD）
- POST /api/ai/* 前校验 configured（未配置 400 提示去设置）；调用 ai_service；统一 500 包装
- 测试：未配置 400、已配置走 mock 成功

### Task 6: 前端
- 设置弹窗（顶栏 ⚙ → 弹窗：Base URL/模型名/Key/保存/状态徽章）
- 右栏解锁：Ask 输入、工具坞（无配置时仍禁用并提示）
- Ask 链路：发送 → POST → 卡片渲染 + 插入
- 改写链路：工具坞/选中 → POST → 候选卡 + 接受替换（沿用绿色高亮）
- 洞察链路：打开草稿 → POST insight → 渲染洞察卡 + 建议列表（可执行）
- 验证：浏览器手动全链路 + 控制台无错误

### Task 7: 集成验证
- pytest 全绿；hermes verify test PASS
- 起服务：未配置状态 → 设置弹窗引导 → （用户配 key 后）真调用验证
