# 文序 · 推广渠道与节奏清单

> 诚实前提：单人、本地工具、零预算。冷启动靠的是"真实用户的口碑 + 内容复利"，不靠投流。
> 目标不是"爆"，是拿到 **20~50 个真实试用 + 20 条真实卡点反馈**——那才是产品继续进化的燃料。

## 第一步：内测（先别急着公开）

**找 3~5 个真实写作的人**（写公众号/知乎/专栏的朋友、写手群），每人发安装包，请他们各写一篇 3000 字文章，记录：

- 从下载到写出第一句花了多久、卡在哪；
- 哪一步想骂人；
- 有没有差点丢掉稿子、AI 有没有改坏文章。

**为什么先内测**：第一次公开亮相如果翻车（装不上、卡死、模型配置劝退），冷启动就结束了。先修卡点，再放量。

## 第二步：首波发布（按性价比排序）

| 渠道 | 怎么做 | 预期 | 备注 |
|---|---|---|---|
| **V2EX**（程序员社区） | 发"创造者"节点帖子，标题用"我给自己写了一个 AI 写作工具" | 流量最稳、反馈最毒舌（有用） | 会有人杠"为什么不用 XX"——准备好答案：不是替代，是写作工作台 |
| **掘金 / 少数派** | 投一篇"产品思路 + 技术实现"长文（本地优先、证据链、候选制怎么设计的） | 长尾流量，读者质量高 | 少数派需投稿审核，标题要"人"味 |
| **即刻** | 发动态 + 配 3 张截图，挂 GitHub 链接 | 小圈子转发快 | 适合持续更新进度，攒早期关注 |
| **知乎** | 回答"AI 写作工具推荐/AI 编造引用怎么破"类问题，文末带产品 | 长尾精准流量 | 先认真回答，产品只是答案的一部分 |
| **小红书** | "写作工具"关键词笔记：截图 + 使用前后对比 | 女性/内容创作者用户群 | 标题要结果导向："改稿时间省一半" |

低性价比（暂不碰）：ProductHunt（中文本地工具转化差）、B 站（需视频制作成本）、公众号（没粉丝时自嗨）。

## 第三步：复利内容（每周 1 篇，发上面任意渠道）

1. **"用文序写一篇 X"系列**：把真实写作过程录屏/截图成文——比任何功能列表都有说服力；
2. **对比测评**：文序 vs 通用大模型直接写 vs 其他 AI 写作工具，重点展示"核验"和"不改稿"；
3. **开发日志**：为什么做 BYOK、为什么不做云、证据链怎么设计——技术圈吃这套，还会顺手给 star。

## 长期指标（每周看一次）

- GitHub star / Release 下载数（Release 页面自带下载统计）；
- Issues 里来自**陌生用户**的反馈条数（最关键的北极星）；
- 从"下载"到"填好 Key 写出第一段"的转化——如果这里断崖，先修引导，别再发渠道。

## 一句话总结

> 引流不是发一条帖子，是**让每个真实用户愿意把他的写作体验告诉下一个人**。文序最值钱的卖点只有三个：不丢稿、不乱改、不装懂——把这三点让用户亲身体验到，人自然会来。
