# 文序 dogfood 检测报告（2026-08-13）

检测方式：浏览器全功能实测 + API 直连验证 + 真实 AI 链路（DeepSeek key 已配）。
范围：全站（项目/草稿/编辑/AI 五链路/引用/素材/成稿检查/历史/导出/设置/规则建议）。

## 结论速览

- **能用且好用的**：洞察、Ask（含偏好注入）、改写候选生成、搜索（流式）、核验（证据诚实）、撤销、历史、autosave、双版本导出、成稿检查主体、侧栏收起
- **用不了/有错的**：5 个 bug（1 个已当场修复），其中 2 个直接伤害创作者信任
- **右栏评估**：骨架对、灵魂还差（详见第二部分）

## 一、用不了/有错的（bug 清单）

### Bug 1（High，未修）降级搜索结果「引用」「存入素材」必失败
- 现象：外网受限时搜索降级为模型知识（source=model），结果无真实 URL；但按钮仍显示，点击报 `400 来源地址不能为空`
- 影响：用户在外网受限环境（当前环境就是）引用/素材功能完全不可用
- 建议：无 URL 的结果隐藏这两个按钮，或提示"模型知识结果无法引用，需联网搜索"

### Bug 3（High，未修）改写接受后正文拼接断裂
- 现象：选中 60 字 → 改写 → 接受方案一（整段重写）→ 正文出现「阐明一个观点：……个更朴素的判断」乱码
- 根因：AI 候选是整段重写，但替换只发生在选区范围，选区外的原文残留，拼接错位
- 影响：**最核心功能破坏正文**，一次乱码足以摧毁信任；乱码会随导出带出去
- 建议：接受时按句子边界扩展替换范围（句首→句尾），或候选覆盖整段时整段替换

### Bug 5（High，已修复 ✓）块标记→规则建议失效
- 根因：draft_open 信号无条件覆盖 focus=article，冲掉 mark 信号设定的 focus=block → 规则不匹配 → 建议列表空
- 修复：draft_open 只设 stage，不覆盖更新信号已定的 focus/issue（commit 8822e17，232 测试无回归）
- 修复后实测：标记「表达不顺」→ 建议卡（改写这段 + 理由 + 执行/关闭）→ 执行 → 改写链路 ✓

### Bug 8（Medium，未修）回收站无 UI 入口
- 现象：删除草稿提示"移入回收站（可恢复）"，但界面上没有任何地方能看到回收站、恢复已删草稿
- 后端 API 正常（/api/projects/{pid}/trash + restore 均可用）
- 影响：「可恢复」承诺无法兑现，删了就找不回来

### Bug 9（Low）首页右栏过时文案
- 「AI 接入后启用」「第一阶段的 AI 建议在下一阶段接入」——AI 早已接入，误导新用户

### Bug 10（Medium，体验）成稿检查噪音
- 实测 13 项问题中 10 项是「事实性主张待核实」，把"摄影没有取代画家""计算器没有取代数学家"这类比喻句全标成待核实
- 影响：观点文的正常修辞被当作问题轰炸，创作者会觉得 AI 不懂文体
- 建议：观点文规则包排除修辞/比喻句式，或降级为不显示

## 二、右栏 AI 写作助手：真的起到作用了吗？（创作者视角）

**实测结论：骨架对，灵魂还差。当前它在"被召唤时"可靠，但"在场感"为零。**

### 起作用的部分（真实体验证据）
1. **洞察质量好**：准确说出"这段在说"、指出"缺具体案例/数据支撑核心论点"——这是创作者真正需要的判断辅助
2. **Ask 懂你的偏好**：存了"多用短句，少用被动语态"后，改写"他把报告写完了，报告被大家传阅了"→"他写完报告，大家传阅了"——偏好真的生效
3. **核验诚实**：抓不到证据时明确说"未能抓取到可核验来源，当前判断基于模型知识"——不虚构可信度，这比给出假答案有价值得多
4. **撤销可靠**：接受 AI 改写出乱码后 Ctrl+Z 完美还原——补救机制存在

### 没起作用的部分（创作者的真实痛点）
1. **AI 在写作中最该在的时刻是缺席的**。整个写作过程（打字、删改、卡壳）右栏纹丝不动，洞察要手动点、建议要手动标记。理念是"问题发生在哪里，AI 就在哪里解决"，但实际是"用户发现问题后 AI 才被召唤"。创作者卡壳时不会去点按钮，他只会盯着屏幕。
2. **改写会弄坏正文（Bug 3）**。创作者对工具的最低期待是不破坏他的文字。一次乱码，整个工具就不再被信任。
3. **"关心"太机械**。成稿检查把修辞当事实审查（Bug 10），AI 的辅助显得不懂写作、不懂文体。
4. **降级链路半残**。外网受限时搜索能用（模型知识），但紧接着的引用/素材全失败（Bug 1）——给了一半的功能比不给更让人困惑。

### 判断
右栏形态（非对话、建议可执行、历史沉淀）是对的，冻结决策正确。但它目前是一台"可靠的应答机"，还不是"写作助手"。要变成真正的助手，优先级：

1. **修改写断裂**（信任底线）
2. **修降级链路按钮**（诚实底线）
3. **让 AI 在写作中"在场"**：检测停顿/反复删改，主动给出低打扰提示（Phase 6 已埋了信号上报的基础设施，只差触发端）
4. **让检查懂文体**（噪音）
